# LLM Bridge

Телефон на Android подключается по Wi-Fi Direct, без роутера, к языковой модели на домашнем ПК.
Всё работает локально: живые персонажи, истории в виде визуальной новеллы, квесты, картинки.

```
Телефон (android/) ──Wi-Fi Direct──▶ мост на ПК (pc/) ──▶ llama-server      текст
                                                     └──▶ sd-server         картинки
```

## Что где лежит

```
llm-bridge/
├── run.sh            запуск моста на ПК
├── deploy.sh         сборка приложения и установка на телефон
├── pc/               мост: окно, API для телефона, память, персонажи, рисование
├── android/          приложение (Kotlin, Compose)
├── scripts/          установка: инструменты, модели, переезд со старой структуры
├── docs/             план (ROADMAP.md) и список проверок (ПРОВЕРКА.md)
├── tools/            llama.cpp и stable-diffusion.cpp — собираются скриптами, в git не попадают
├── models/           модели: llm/, image/, lora/, upscale/, whisper/ — в git не попадают
└── data/             личное: настройки, токен, чаты, карточки, картинки — в git не попадает
```

Версия переносная: всё, что нужно для работы, лежит в этой папке, пути в настройках записаны
относительно неё. Папку можно переименовать, перенести на другой диск или компьютер — чаты,
персонажи и модели переедут вместе с ней. Вне проекта остаются только системные вещи, которые
ставит `pc/install.sh` (helper для Wi-Fi Direct в `/usr/local/sbin`, правило sudo), и запись
автозапуска; на новом компьютере достаточно запустить `pc/install.sh` и собрать инструменты.

## Установка с нуля

```bash
./pc/install.sh                  # зависимости моста, доступ к Wi-Fi Direct (потом перезагрузка)
./scripts/setup-llama.sh         # llama.cpp с CUDA → tools/llama.cpp
./scripts/setup-helper.sh        # маленькая фоновая модель → models/llm/helper
./scripts/setup-images.sh --qwen --moss   # stable-diffusion.cpp и модели картинок
```

Текстовую модель (`.gguf` и её `mmproj`) положите в `models/llm/` и выберите в окне моста.

## Каждый день

```bash
./run.sh        # мост
./deploy.sh     # собрать приложение и поставить на телефон
```

## Переезд со старой структуры

Раньше мост лежал в `~/llm-bridge`, приложение — в `~/llm-bridge-android`, модели — в `~/models`,
инструменты — в домашней папке, чаты и настройки — в `~/.local/share` и `~/.config`. Скрипт переносит всё в папку проекта и правит настройки:

```bash
python3 scripts/migrate-layout.py        # показать план, ничего не меняя
python3 scripts/migrate-layout.py --go   # выполнить
```
