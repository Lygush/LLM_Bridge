# Личные данные

Всё, что появляется во время работы, лежит здесь и в git не попадает (см. `.gitignore`):

```
data/
    config.json            настройки моста, токен и пароль сети Wi-Fi Direct
    image_profiles.json    профили моделей изображений
    chats.db               чаты, карточки персонажей и миров, память, отношения
    images/                картинки: присланные и нарисованные
```

Резервная копия — это копия этой папки (при закрытом мосте). Перенос на другой компьютер —
вместе со всем проектом или только с этой папкой.
