# Модели

Файлы моделей в git не попадают (см. `.gitignore`) — они скачиваются скриптами из `scripts/`.

```
models/
    llm/          текстовые модели (.gguf) и их mmproj — список «Текстовая модель» в окне моста
    llm/helper/   маленькая фоновая модель на процессоре      scripts/setup-helper.sh
    image/        модели изображений: диффузия, энкодеры, VAE  scripts/setup-images.sh
    lora/         LoRA для картинок
    upscale/      апскейлеры
    whisper/      распознавание речи (на будущее)
```

Текстовую модель мост не скачивает: положите `.gguf` (и её `mmproj`, если модель видит картинки)
в `models/llm/` и выберите в окне моста.
