# LLM Bridge — Android-клиент

Чат с моделью на ПК через Wi-Fi Direct. Пара к ПК-приложению `llm-bridge` (API 2).
Требования: Android 10+.

## Сборка

```bash
cd android
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64   # JDK из Android Studio (25) Gradle не понимает
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk` — копируется на телефон и ставится поверх.
(APK из `intermediates` после запуска ▶ в Studio телефон не примет: он помечен как тестовый.)

## Как работает

- Сопряжение — один раз, по QR «Для приложения» на ПК.
- Служба в уведомлении держит связь, пока приложение свёрнуто или экран выключен;
  кнопка «Отключить» в уведомлении разрывает связь до следующего открытия приложения.
- При обрыве приложение само переподключается: входит в группу Wi-Fi Direct ПК,
  проверяет мост, открывает поток событий и догружает пропущенное.
- Чаты хранятся на ПК. Боковая панель (☰) — список чатов и «Новый чат».
- Долгое нажатие на сообщение: копировать, изменить, изменить и отправить заново
  (своё), перегенерировать (ответ модели), удалить. Стрелки ‹ › — варианты.
- Полоска под заголовком — заполнение контекста модели.
- Меню ⋮: системный промпт (для чата и/или по умолчанию), переименовать или удалить чат,
  переподключиться, забыть ПК.
- ⋮ → «Параметры генерации»: тумблер размышлений, пресеты (Рекомендуемые / Точный /
  Творческий), ползунки. Нажатие на значение возвращает «авто».
- ⋮ → «Память чата» или нажатие на полоску контекста: факты (★ — закрепить),
  хроника (можно править), раскладка контекста по слоям.
- В меню сообщения: «Закрепить» (всегда в контексте), «Продолжить» для оборванного ответа.
- Ответы оформляются markdown: заголовки, списки, **жирный**, *курсив*, `код`, блоки кода
  с кнопкой «Копировать», цитаты, таблицы, ссылки. Текст выводится плавно (буфер).
- Кнопка «+» слева от поля ввода — фото из галереи или камеры (до 4, сжимаются до 1280 px).
  Нажатие на фото в чате — просмотр на весь экран.
- «+» → «Нарисовать…»: запрос (текст из поля подставляется), модель, размер, шаги, сид.
  Ход рисования — в пузыре ответа; «Перегенерировать» у картинки рисует заново.
