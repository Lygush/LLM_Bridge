# LLM Bridge — план развития

Цель — развлекательная: живые персонажи, истории, игры. Всё локально: телефон ↔ ПК по Wi-Fi Direct.
Ручное управление (рисование, правка, перегенерация) остаётся всегда, модель берёт на себя максимум.

## Сделано

- Этап 0–1: связь, чаты-деревья (варианты, ветки), память (факты, хроника, закрепления), параметры.
- Этап 2–4: markdown, плавный вывод, фото, генерация изображений (sd.cpp, переключение видеопамяти).
- Шаг 1: модель рисует в диалоге (`draw_image`), видит нарисованное, пометки, карточка картинки,
  «улучшить промпт», режим иллюстраций; папки моделей `models/{llm,image,lora,upscale,whisper}`.
- Шаг 2: персонажи и персоны (заполняет модель), портреты, миры с лорбуком, сцены с несколькими
  персонажами, квест (модель — ведущий, состояние, варианты), история (продолжи/поворот/перепиши),
  «переписать с пожеланием», удаление чатов без связи.

- Ночь 9→10 ноября: фоновая модель (CPU) и чувство времени; режим «Чат»: отношения
  (симпатия, доверие, статус, настроение, обещания, подсказки «💭»), отказы по отношениям,
  переписка (несколько пузырей) / рядом, распорядок дня, вкусы, тайна, «пишет первым» при входе,
  монеты и подарки, награды в квестах; режим «Я ведущий» с помощником ведущего;
  «История» как визуальная новелла: кадры (место / повествование / реплика с эмоцией),
  фоны мест (рисуются один раз), эмоции персонажа (6 спрайтов), экран с листанием по нажатию.

## Три режима — к чему идём

### Чат — как переписка с живым человеком
- Отношения «персонаж × персона»: симпатия, доверие, статус (незнакомец → знакомый → друг →
  близкий; неприязнь → враг), настроение (со временем возвращается к норме).
  Общие для всех чатов с этим персонажем. Обновляет фоновая модель после каждого обмена.
- **Решение: показ отношений — настройка** (скрыто / видно; при скрытых — подсказки вроде
  «Мире понравилось»).
- Персонаж решает сам: «скинь фотку» → может отказать (не близки, нет симпатии, плохое
  настроение) или согласиться; рисование — его решение. Тайны открываются при высоком доверии.
- Ощущение мессенджера: модель знает время и сколько вы молчали; короткие сообщения, иногда
  несколько подряд; «печатает…», «был в сети».
- Персонаж может написать первым — **только при входе в приложение. Уведомлений не надо.**
- Персонаж меняется: после важных событий модель предлагает обновить карточку (с подтверждением).
- Селфи: стиль камеры телефона, одно лицо по портрету (нужен шаг 3).
- Распорядок дня: работа, досуг, сон. Ночью отвечает сонно или «утром напишу», на работе занят;
  селфи — там, где он сейчас.
- Персонажи знают друг о друге: ревность, обиды, своё мнение о ваших друзьях. Отношения
  персонажей между собой тоже хранятся.
- Повод для разговора: при входе персонаж приходит с темой («смотри, что нашла», «у меня
  проблема», «помнишь, ты обещал…»), а не с пустым «привет».
- Обещания и последствия: модель замечает обещания, потом спрашивает; нарушенное бьёт по доверию.
- Подарки за внутриигровую валюту. Валюта общая (кошелёк персоны): зарабатывается в квестах,
  можно одолжить (и вернуть долг — или нет, с последствиями). Подарок не обязательно понравится —
  реакция по вкусам и настроению персонажа.
- **Свидание / вечер с персонажем** — запускается прямо из чата как отдельная короткая новелла
  (на базе режима «История»): выбор места, сцены, развилки; итог влияет на отношения в чате.

### История — визуальная новелла
- Вы задаёте ход сюжета, модель раскрывает сцены, описывает, рисует.
- Ответ модели — кадры: повествование / реплика (говорящий, эмоция) / смена локации.
- Экран новеллы: фон по локации (рисуется при смене места, кэшируется), спрайт говорящего
  с эмоцией, имя в рамке, ключевые моменты — полноэкранная иллюстрация.
- **Решение: текст листается по нажатию** (как в классических новеллах). Переключатель
  «новелла / текст».
- Набор эмоций персонажа (спокойный, радость, злость, грусть, смущение, удивление) рисуется
  один раз по портрету.
- Развилки с последствиями и «карта выборов» в конце (пройденные и непройденные ветки).
- Галерея истории: все кадры, фоны, спрайты — альбомом.
- Режим «режиссёр»: кадр одной строкой → фон, поза, эмоция, текст.
- «В предыдущих сериях»: краткий пересказ при возвращении к давней истории.

### Квест
- Модель — ведущий (есть). Позже, если понадобится: честные кубики (бросает ПК), лист
  персонажа с навыками, проверки, достижения.
- **Новое: вы — ведущий.** Модель играет героя или отряд (персонажи из карточек), реагирует,
  спорит, решает. Кнопка «помощник ведущего»: придумать место, реплику NPC, осложнение.
- Карта мира: граф локаций, туман над неисследованным; можно нарисовать карту картинкой.
- Отряд спутников из карточек: свой характер, отношения с вами, могут не согласиться или уйти.
- Генератор приключений: одной кнопкой — завязка, 3–5 сцен, злодей, финал; ведущий держит план,
  но подстраивается.
- Награды — во внутриигровой валюте (общий кошелёк с режимом «Чат»).

## Общая основа
- Маленькая фоновая модель на CPU (1–4B): отношения, состояние, разметка кадров, факты,
  подписи. Проверить качество; если справляется — переносим туда фоновую работу.
- Чувство времени: текущее время и пауза с прошлого сообщения в контексте.
- Видеопамять: каждая картинка = выгрузка LLM и загрузка модели изображений. Фоны и спрайты —
  кэшировать и рисовать пачками; проверить, влезет ли маленькая модель изображений рядом с LLM.

- 10 ноября: MOSS-Image (профиль, загрузка); шаг 3 — роли профилей, похожие лица по портретам
  (Qwen-Image 2.1 + зрение), поза по присланному фото, надписи — MOSS; эмоции по портрету;
  персонажи знают о других знакомствах, «Знакомства» в карточке; долги (занять / вернуть);
  свидание из чата как новелла с итогом в отношения; «в предыдущих сериях».

- 10 ноября, днём: персонаж меняется (модель предлагает правку карточки, решаете вы);
  новелла — развилки «[Выбор: …]» кнопками, карта выборов, галерея, «🎬 Кадр», фоны вручную.

## Идеи в запасе
- Персонаж-рассказчик: история или страшилка на ночь в его стиле, с картинкой.
- «Угадай, кто я»: модель играет загаданного персонажа, вы угадываете.
- Мир растёт сам: новые места и люди из истории модель предлагает добавить в лорбук.
- Похожий персонаж / мир: «такой же, но злой», «тот же мир через 100 лет».
- Экспорт и импорт карточек (персонаж, мир) с портретом в файл.
- Детектив с запечатанной разгадкой (виновный хранится на ПК, модель не может подыграть), блокнот улик.
- Мини-игры с персонажами: «20 вопросов», загадки, «Мафия», карты.
- Ток-шоу / спор персонажей, вы — судья. Персонажи общаются между собой, вы вмешиваетесь.
- «А что если…» — ветку разговора в новый чат.
- «Удиви меня» — случайный персонаж / мир / завязка в одно нажатие, с темой.
- Персонаж из фото (кот, кружка, вы) — характер и портрет в стиле мира.
- Комикс из сцены (4–6 кадров с репликами). Книга из истории (EPUB/PDF с иллюстрациями).
- Режим визуальной новеллы и для чата (портрет меняет эмоцию).
- Виджет на главном экране, картинку — на обои.
- Дерево вариантов разговора.
- Своя модель на чат (творческая / точная), спекулятивное декодирование.

## Отложено
- Лента персонажей — не нужна.
- Звуки и музыка сцены (фон таверны, дождь), аудиокнига — может, потом.
- Документы и «Поделиться» — не нужны (цель развлекательная).
- Импорт карточек SillyTavern — не нужен.
